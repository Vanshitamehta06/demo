# Website For Flight Booking API

REST API generated by Intent2Deploy AI from the request: "create a website for flight booking and our app should name as vanshita flight service".

## Run

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8010
```

Interactive docs: http://127.0.0.1:8010/docs

If port 8010 is already in use, pick another one, e.g. `--port 8020`, and open that port instead.

## Test

```bash
python -m pytest -q
```

## Docker

Build and run the image:

```bash
docker build -t website-for-flight-booking-service .
docker run --rm -p 8010:8000 website-for-flight-booking-service
```

Or with Docker Compose:

```bash
docker compose up --build
```

Then open http://127.0.0.1:8010
(health check: http://127.0.0.1:8010/health). If port 8010 is busy, change
the left side of the port mapping (e.g. `-p 8020:8000`).

CI builds this image and checks the running container on every pull request and after each merge
into `staging` and `main` (`.github/workflows/docker.yml`).
