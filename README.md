# Food Delivery App — Login

Interactive sign-in and sign-up page with a FastAPI backend.

Generated by Intent2Deploy AI from the request: "build a login page for a food delivery app".

## Run

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000.

## Test

```bash
python -m pytest -q
```

## Notes

- Passwords are hashed with PBKDF2-SHA256 and a per-user salt.
- Accounts and sessions are kept in memory; add a database and token expiry before production use.
